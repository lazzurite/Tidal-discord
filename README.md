# TIDAL Discord

A lightweight Windows application that displays the currently playing TIDAL track in Discord Rich Presence.

## Requirements

- Windows 10/11
- TIDAL
- Discord

## Usage

1. Install **TIDAL Discord** using the installer.
2. Open **Discord**.
3. Open **TIDAL** and start playing a track.
4. TIDAL Discord will automatically display the current track in your Discord Rich Presence.

Discord and TIDAL must be running for the application to work.

## Features

- Track title and artist
- Playback progress
- Pause and resume status
- TIDAL logo
- YouTube search button for the current track
